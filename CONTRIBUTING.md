# Contributing

The most useful contribution is a correction. Prices change, pages move and mistakes happen, and a dataset like this is only as good as how quickly wrong rows get fixed.

## Report a wrong or outdated price

1. Open an issue with the **Price correction** template.
2. Include the tool and plan, what the row says, what you believe is correct, and a link to the vendor's own page showing it.
3. A screenshot helps but is not enough on its own. The vendor page is the source of truth.

Corrections are checked against the vendor's own page before any row changes. If the report is accurate, the old row is marked `stale` and a corrected row is added, so the history stays visible. If a report cannot be confirmed from a primary source, it is closed with a note explaining why. Every report is reviewed, but not every report results in a change.

## Suggest a tool to add

Open an issue with the tool name, the vendor's pricing page and why it belongs in the dataset. Tools are added when their pricing can be verified from a primary source under the rules in [METHODOLOGY.md](METHODOLOGY.md).

## Pull requests

Pull requests that change data must include the vendor source URL and the date you checked it, and must follow the column rules in the data dictionary. Pull requests that add promotional wording, affiliate or tracking links, or unsourced figures will be closed.

## Corrections policy

This repository follows the same principles as the site's [Corrections Policy](https://aihustleworld.com/corrections-policy).
