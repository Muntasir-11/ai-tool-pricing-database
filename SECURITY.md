# Security Policy

This repository publishes a static dataset (CSV) and documentation. It doesn't run any code, so "security" here mainly covers data integrity and this repository's own GitHub configuration — not a software vulnerability in the traditional sense.

## Reporting a Problem

If you find any of the following, please report it privately instead of opening a public issue:

- A data entry that looks tampered with or maliciously misleading (not just outdated — see CONTRIBUTING.md for ordinary price corrections)
- A security issue with this repository's GitHub configuration, such as a leaked credential or a malicious workflow file
- Anything else you don't think should be discussed in the open before it's fixed

Email **muntasir@aihustleworld.com** with details. You should get a response within a few business days.

For an ordinary outdated or incorrect price, please use the "Price correction" issue template instead — that's not a security matter.

## Supported Scope

Only the `main` branch and the latest published data are in scope. There are no software dependencies in this repository to patch.
